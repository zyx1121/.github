# Security Policy

## Supported versions

Only the latest release of each project receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Preferred: GitHub private vulnerability reporting (the repo's Security tab, "Report a vulnerability").
- Or mail [yongxiang.zhan@outlook.com](mailto:yongxiang.zhan@outlook.com).

Include steps to reproduce and the affected version. You will get a first response within 7 days.
